快速开始（Safari）

  1. 打开 MutualX 应用，点击前往 Safari 扩展设置。
  2. 在「Safari 浏览器 → 设置 → 扩展」中勾选启用 MutualX，并允许访问 x.com / twitter.com。
  3. 打开 X 页面，点击工具栏的 MutualX 图标即可开始扫描。

常见问题

  • 需要重新登录或授权 API 吗？ 不需要。MutualX 直接使用你当前已登录的 X 网页会话，不请求额外第三方权限。
  • 数据会上传到服务器吗？ 不会。所有扫描结果与忽略名单均仅保存在浏览器本地。

Quick Start (Safari)

  1. Launch the MutualX app and open Safari Extensions preferences.
  2. Enable MutualX in Safari Settings → Extensions and allow access on x.com and twitter.com.
  3. Open X and click the MutualX toolbar icon to scan your following list.

FAQ

  • Do I need to sign in again or connect an API key? No. MutualX works directly with your active logged-in X session.
  • Is any data sent to external servers? No. All scan results and ignore lists remain strictly in local browser storage.
